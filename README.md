# ✈️ Airline Passenger Experience Analytics & Satisfaction Prediction

An end-to-end data analytics and machine learning project using 120K+ airline passenger records to analyze customer satisfaction and predict passenger satisfaction.

## 🔍 Key Work

- Performed data cleaning, preprocessing and exploratory data analysis using Python, Pandas and NumPy.
- Analyzed satisfaction patterns across passenger demographics, travel class, delays and service quality.
- Built an ML pipeline with feature engineering, Logistic Regression and Random Forest for satisfaction prediction.
- Achieved **96.33% accuracy** using the best-performing Random Forest model.
- Developed an interactive Power BI dashboard with KPIs, slicers, comparative charts and drill-down visualizations.

## 🛠️ Technologies

Python | Pandas | NumPy | Scikit-learn | Power BI | DAX | Power Query | Jupyter Notebook

## 🎯 Objectives

- Understand key factors affecting passenger satisfaction
- Predict passenger satisfaction using machine learning
- Analyze operational and service-quality performance
- Present actionable insights through interactive dashboards
